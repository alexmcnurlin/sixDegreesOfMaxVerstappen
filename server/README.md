# Server

## Development

- Run
  - `npm run build` - Compiles app to `lib/`
  - `npm run build-watch` - Compiles app, and will rebuild if there are any conde changes
  - `npm start` - Start server
  - `npm run start-watch` - Start server, and reload if there are any code changes
    - To rebuild build AND re-run on change, see `npm run start-server` in the root of the project
- Test
  - `npm test` - Playwright tests
